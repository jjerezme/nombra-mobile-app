# 005. Textos con gen-l10n

- Estado: aceptada
- Fecha: 2026-11-23

## Contexto
Toda cadena visible debe estar en español e inglés con las mismas claves.

## Decisión
`flutter gen-l10n` con `lib/l10n/app_es.arb` (plantilla) y `app_en.arb`. El código generado `app_localizations*.dart` se versiona y se excluye del análisis. Un test comprueba que ambos archivos tengan las mismas claves.

## Consecuencias
Tras editar un `.arb` se ejecuta `flutter gen-l10n`. Las claves van en `camelCase` con el nombre de la pantalla como prefijo (`homeTitle`).
